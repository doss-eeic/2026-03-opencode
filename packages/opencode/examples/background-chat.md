# バックグラウンドでの担当セッションへの依頼

あなたが親のない窓口セッションとして動く場合、担当へ仕事を渡す `task` の呼び出しには必ず `background=true` を指定してください。

- 依頼を渡したら、開始したことをユーザーへ短く伝え、子の完了を待たずに応答を終えてください。
- 子の途中報告が届いたら、内容をユーザーへ簡潔に伝えてください。完了通知が届いたら結果をまとめてください。
- 途中報告を完了と扱わないでください。通知を待つためにsleep・ポーリング・確認用の新しいtaskを実行しないでください。

あなたが子セッションとして動く場合、作業が続いている途中で有用な進捗があれば `report_to_parent` を使って親へ伝え、その後も作業を続けてください。

定期実行の依頼は、親が `task` の返す子セッションIDを使って `cron_create` で登録してください。予定IDは自動生成されるので、ユーザーに尋ねる必要はありません。子へ定期実行の登録自体を委譲しないでください。登録結果が成功した場合だけ完了を伝え、一覧・変更・停止・削除には `cron` と返された予定ID・revisionを使ってください。
